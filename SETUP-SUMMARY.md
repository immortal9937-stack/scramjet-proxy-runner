## 💾 **HOW TO USE ON iOS (5 Minutes)**

### Using Safari + Files App:

1. **On your iPhone, open Safari**
   - Go to: `https://github.com/immortal9937-stack/scramjet-proxy-runner`

2. **Find and copy HTML**
   - Click `COPY-PASTE.html`
   - Click "Raw"
   - Select all text (tap, then "Select All")
   - Copy

3. **Save as file**
   - Open **Files** app
   - Tap "Browse" → "On My iPhone"
   - Create folder called "HTML"
   - Inside folder, create new file
   - Name: `proxy.html`
   - Paste the code
   - Save

4. **Open in browser**
   - Find the file in Files app
   - Tap it
   - Select "Open in Safari"

5. **Use the app**
   - Enter URL: `https://example.com`
   - Select mode (keep HTTPS)
   - Tap "Start"
   - Watch the logs!
