# 🚀 QUICK START - Scramjet Proxy for iOS

## ⚡ 30-Second Setup

### Step 1: Get the Code
Go to: **https://github.com/immortal9937-stack/scramjet-proxy-runner**

Click on one of these files:
- `COPY-PASTE.html` ← **Easiest** (already has instructions)
- `standalone.html` ← Alternative

### Step 2: Copy All Code
- Click "Raw" button
- Select all (Ctrl+A or Cmd+A)
- Copy (Ctrl+C or Cmd+C)

### Step 3: Save as File

**On iPhone/iPad:**
1. Open **Notes** app
2. Create new note
3. Paste the code
4. Tap "Share" button (↗️)
5. Select "Files"
6. Choose location (Documents)
7. Name it: `proxy.html`
8. Tap "Save"

**Or use Files App directly:**
1. Open **Files** app
2. Tap "Edit" → "New Folder"
3. Name it "HTML"
4. Open the folder
5. Tap the **+** icon
6. Select "Create Document"
7. Name: `proxy.html`
8. Paste code

### Step 4: Open in Browser
1. Open **Files** app
2. Find your `proxy.html` file
3. Tap it
4. Select "Open in Safari" (or Chrome)
5. ✅ Done!

## 🎯 Using the App

**In the proxy app:**

1. **Enter URL** → `https://example.com`
2. **Select Mode** → Keep HTTPS selected
3. **Choose Type** → GET (default)
4. **Tap "Start"** → Watch the logs
5. **See Results** → Status box shows if it worked

## ❓ Troubleshooting

**Q: File won't open**
- Make sure extension is `.html` (not `.txt`)
- Try opening in Chrome or Firefox instead

**Q: Looks weird on my phone**
- Refresh the page (swipe down at top)
- Try landscape mode

**Q: Can't find the file**
- Search for `.html` in Files app
- Check Documents folder
- Try a different location

**Q: How do I delete it?**
- Long-press file in Files app
- Select "Delete"
